# 考研英语一写作评分标准

## 试卷结构与共同原则

| 题型 | 分值 | 通常篇幅 | 主要评阅依据 |
| --- | ---: | --- | --- |
| A 节应用文 | 10 | 约 100 词 | 信息是否齐全，安排是否好读，语言是否准确，格式和语气是否合乎写作对象及目的。语言多样性依任务判断。 |
| B 节短文 | 20 | 160–200 词 | 题面任务是否覆盖并展开，结构和推理是否连贯，词汇及句式是否准确并有适当变化。材料可为文字、图画、图表或组合。 |

按全文的任务完成度和语言表现综合定档，再选档内分。具体题面的字数、体裁和格式要求优先。偏离字数要求可酌情处理。可使用题面关键词，大段照搬提示语会影响评阅。拼写和标点的影响视其对理解和交际的影响而定，英式和美式用法均可接受。出版社样章还说明，笔迹确实妨碍理解时可降一档。模考时应以可观察的阅读困难为依据。以下分档依据清华大学出版社样章表 1.1 转述，训练反馈中的任务核对和错误类别用于解释综合判断。

| 档次 | A 节 | B 节 | 综合表现 |
| --- | ---: | ---: | --- |
| 第五档 | 9–10 | 17–20 | 各项任务均有充分回应。用词与结构有变化且准确，组织清楚，语体恰当，少有语言错误。 |
| 第四档 | 7–8 | 13–16 | 任务完成较好，个别要点展开不足。语言有一定变化且大体准确，读者能顺畅读懂，格式和语气较合适。 |
| 第三档 | 5–6 | 9–12 | 覆盖多数要点，仍有遗漏或发展有限。词汇和结构能支撑基本表达，有些错误但大意可读。段落关系和语体大体成立。 |
| 第二档 | 3–4 | 5–8 | 任务有较明显的遗漏、展开不足或无关内容。语言和衔接问题多，读者难以准确获取信息。 |
| 第一档 | 1–2 | 1–4 | 主要任务未完成或内容大多偏离。语言单一且错误密集，组织和文体难以支撑理解。 |
| 零档 | 0 | 0 | 作答与题意全无关系，或可评阅内容太少，或作答本身无法辨认。 |

上表用于整体匹配。参考相邻档时，优先看缺失的是关键任务还是局部细节、误差是否改变含义、论述是否具体以及错误是否反复影响理解。高档内的最高分需要全面、稳定的完成度。

## 档次边界的判断

下列是模拟批改时用来解释档次差别的依据，遇到内容和语言表现不在同一档时，以全文完成度和交流效果综合判断。

| 边界 | 定档时问什么 |
| --- | --- |
| 第五档与第四档 | 要点是否只是提到，还是具体做到了题目要求？议论有无论据和可追踪的推理？语言准确性是否从头到尾稳定？ |
| 第四档与第三档 | 问题是一个次要细节展开偏浅，还是明确任务没有完成？少量瑕疵是否仍保留全文意思，还是错误反复让读者猜？ |
| 第三档与第二档 | 读者是否仍能掌握多数任务的主要意思？关键任务缺失或理解成本过高时，检查第二档是否更吻合。 |
| 第二档、第一档与零档 | 区分偏离一部分、只剩少量相关内容、完全无关或作答不足以评阅。只对照已核实的题目和可读的答卷，按实际影响判断。 |

档内分看表现靠近哪个边界。有上档空间时，给出一项最可能推动升档的具体修改，如补全来信的第二个问题、把两份材料接到一个成立的论点。四维诊断可分别说明内容、组织、语言与文体卷面的问题，以全文定档为准。词汇和句型多样性按语境判断。常见句型能清楚承载任务时可保留，机械套用导致偏题、语言或组织问题时按实际表现评估。

## 词数与卷别

- 词数优先按题面。用 Python 3 运行随附词数脚本，从标准输入读取英文稿，用空行划段，返回各段与总词数。把正文单独传入可得到正文计数；含称呼、标题、落款的范围要注明。脚本把带撇号的缩约形式、连字符词组、电子邮箱和带点缩写各视作一个计数单位，常规数字也计入。这个结果供练习对照，接近边界时可说明计数差异。传入可辨认的原稿或改稿，删去转录标记和说明文字。
- 明确为英语二时，A 节仍为 10 分、约 100 词。B 节满分 15 分，字数优先看题面，通常约 150 词。从第五档到零档依次为 13–15、10–12、7–9、4–6、1–3、0。两篇都能评分时可合计满分 25 分。来源同下方清华大学出版社样章。
